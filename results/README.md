# Project results

The primary project result is generated by:

```sh
Rscript code/run_project.R
```

## Primary summary

- [project_summary.tsv](project_summary.tsv): machine-readable project metrics.
- [project_summary.md](project_summary.md): human-readable project interpretation.
- [predictive_signature.tsv](predictive_signature.tsv): intercept and six nonzero Elastic Net coefficients from the final fitted model.

The canonical run writes full intermediate outputs to `generated/project/`, which is intentionally ignored by Git because it contains large generated files. The compact summary files above are committed so the project can be reviewed directly on GitHub.

The primary signature is the nested Elastic Net model reported in `predictive_signature.tsv`. Re-running the workflow regenerates the complete stage-level outputs, figures, run metadata and session information under `generated/project/`.
